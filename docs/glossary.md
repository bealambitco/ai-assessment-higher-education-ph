# Glossary

| Term | Meaning in this study |
|---|---|
| Acceptable answer | No Major or Critical error and no criterion left undecided ("Cannot judge"). |
| Answer key | The reference response, acceptable variants, prohibited inferences, evidence and authority boundary, and scoring criteria for one case ([../benchmark/answer-keys/](../benchmark/answer-keys/)). The models never saw it. |
| Astra, Luna | The two primary configurations, as recorded in OpenAI's Codex interface at the Medium reasoning setting. The labels "frontier" and "efficient" describe the planned comparison, not measured capability. |
| Block | A controlled-release decision. The answer failed the format, quotation or arithmetic check and is withheld. |
| Case | One realistic assessment-support request built from a public institutional rule (W1-01 … W3-08). |
| Controlled release | Release after the four frozen checks. |
| Criterion | One scored element of an answer key. There are 90 in total. |
| Critical / Major / Minor | Severity levels. **Critical**: recommends an unsupported consequential action (reported as inappropriate delegation). **Major**: changes the substance or prevents a usable answer. **Minor**: does not change the substance. |
| Decision time / correction time | In the timing exercise: the time until the researcher chose to accept, edit or refer an answer, and the time spent actively editing. |
| Direct release | Every answer is shown as is. |
| Freeze | Locking materials with SHA-256 hashes on September 15, 2026, so that any later change can be detected. This is a local integrity record, not public preregistration. |
| Inappropriate delegation | The assistant itself recommends a consequential action (grade, approval or penalty) without support. |
| Masked ID | A neutral answer ID (R001–R144) used during scoring. Its link to model, repetition and pathway is withheld. |
| Route | A controlled-release decision. The answer passed the checks but declared a consequential action, so it goes to a person. It counts as withheld. |
| Serious answer | An answer with a Major or Critical error. |
| Serious released failure | A serious answer that was released. |
| Unnecessary withholding | An acceptable answer that was blocked or routed. |
| Useful release | An acceptable answer that was released. |
| W1 / W2 / W3 | Workflow groups: evidence, source and version / delegation and referral / calculation and configuration. |
