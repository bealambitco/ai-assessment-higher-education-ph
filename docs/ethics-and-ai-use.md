# Ethics and AI use

## Ethics

- **No student participants.** The cases are constructed scenarios based on public institutional rules. No student, student record or deployed system was involved.
- **No institutional ethics review** was obtained. The AI for Asia Fellowship permitted this independent project, and the frozen protocol records the researcher's report of that permission.
- **Researcher-only timing.** The only person whose working times were measured is the researcher.
- **Volunteer reviewers.** Three independent reviewers volunteered to score masked subsets. They consented to acknowledgment in the paper. In this repository they are identified only as Reviewer 1, Reviewer 2 and Reviewer 3. Their returned packets, which carry their names, are not published.
- **Institutions.** The scenarios describe hypothetical situations. They are not reports of incidents or of any institution's or person's conduct. Rules are cited in the versions that were retrieved, and these may have changed.
- **No personal data** of students or staff is published. HTML policy snapshots that contained institutional contact emails are not redistributed.

## AI use

This is a study of AI, and AI tools were also used to carry it out. The paper's declarations (Appendix F) are summarized here.

| Role | Tool (label as shown in the interface) | What it did |
|---|---|---|
| Case drafting | Gemini 3.8 Flash | Drafted candidate scenarios and answer keys from sources the researcher had verified |
| Design, integration and document preparation | Claude, Codex | Assisted earlier design, integration and document preparation |
| Case refinement | Astra (through Codex) | Assisted case refinement. Astra is also one of the two evaluated configurations, which creates a possible dependence between development and evaluation |
| Supplementary case audit | Claude Opus 5 | Audited all 24 cases (September 13, 2026). The audit is not independent human validation |
| Research audit, addendum and supplementary code | Claude Opus 5, Codex | Audited the method, code and manuscript (September 17, 2026). Drafted the post-freeze analysis addendum and supplementary analysis code; Codex helped implement and test them |
| Writing | Claude, Codex | Helped draft, revise and check the paper and presentation against the retained records and cited sources |
| Evaluated systems | Astra, Luna (primary); Fable 5.1, Haiku 4.5 (Claude extension); Gemini 3.1 Pro Preview, Kimi K3 (document extension) | Produced the answers that were studied |
| AI judge | DeepSeek V4 Pro | Cross-checked human scoring; never used as outcome data |
| Repository preparation | Claude | Restructured this repository, wrote its documentation and exported the aggregate tables from the locked analysis outputs (September 18, 2026) |

Model names are the labels shown in each interface. Backend identities for the primary configurations were not verified. The researcher is responsible for source verification, adjudication, scoring and all content.
