# Paired retained-text extension

Prepared 2026-09-18T11:28:51+08:00. Authorized after primary collection and while initial human scoring is underway. Exploratory, post-collection; not preregistered. No original case, response, reference, criterion or control is altered.

Question: how do evidence location, source support and bounded advice differ when one model receives a retained excerpt versus the retained document text for the same task?

## Design

Six purposively chosen cases, two per workflow, across six institutions, all within the human fallback first 48. Cases were selected for source/task variety and availability of retained full source material, not observed model correctness. See source manifest for rationale. Gemini's label is researcher-reported as Gemini Pro 3.1; exact interface/settings require recording. Kimi K3 is an optional user-proposed replication, with its exact available configuration unconfirmed. Twelve runs per model: one response per case/condition, no generation repeats. Model differences are descriptive; no matched-compute claim.

Both conditions use TXT attachments, identical instructions and identical scenario/task data. The excerpt text is the frozen source_excerpt; the full-text rendering covers all extracted PDF pages or the entire retained HTML text. The PDF originals and HTML are retained locally for provenance but are NOT generation attachments. No browsing, URL retrieval, tools, reference answers, scoring criteria, human judgments or prior model responses are supplied.

This varies the evidence package: content breadth and length, and available location cues differ. It does NOT isolate a pure context-length effect. Full text can add genuinely relevant rules, not only distractors. The study is not an OCR/PDF-layout benchmark or an end-to-end web-retrieval evaluation. Document versions are retained snapshots, not verified current policy.

PDF images are not fully represented by text extraction. Table/equation extraction can cause distortions. Relevant grading passages were checked; Mapua's equation and one row's ≤ glyphs were normalized against the page image, with a separate change log. Other graphical or unrelated content is not certified as a complete visual transcription. Treat any extraction concern as a source-package issue, not automatically a model hallucination.

Condition order alternates across cases (three excerpt-first, three full-text-first). Each run uses a fresh chat. First six runs yield three complete pairs, one per workflow; all twelve yield six. Pick a time cutoff before generation, not after observing interesting answers. Preserve incomplete pairs and access failures in the coverage report; do not omit inconvenient outcomes or replace first attempts.
