# Literature and sources

No full texts are included here: only bibliographic metadata and links.

| File | Contents |
|---|---|
| [source-register.csv](source-register.csv) | The 47 works cited in the paper. Columns: key, APA 7 citation, DOI, URL, evidence tier, source type, peer-review flag, verification status and access or verification date (all re-checked September 17, 2026). Evidence tiers describe what was read: **T1** means the full text or substantial relevant sections; **T2** means the abstract plus verified metadata; **T3** means an official document was opened. `PARTIAL` means the metadata and abstract were verified but the full text could not be re-opened on September 17. A blank status means the entry was checked but no status was recorded. See the paper's Appendix I. |
| [REFERENCES_APA7.md](REFERENCES_APA7.md) | The same 47 works as the paper's reference list, in APA 7. |
| [institutional-sources.csv](institutional-sources.csv) | The 17 institutional documents retained during case development: issuer, title, version, URL, retrieval date, the cases that use the institution's rules, and the SHA-256 and size of the retained copy. Download a document from its URL and compare the hash to confirm it is the version used. The copies are **not redistributed**, because the source register notes "cite; do not redistribute in full". |

Notes on `institutional-sources.csv`:
- `used_in_cases` is at the institution level: the cases that draw on that institution's rules. The exact passage used in each case is quoted in `source_excerpt` in [../benchmark/cases/](../benchmark/cases/).
- Some URLs point to an index page, where the individual clause PDFs are linked (UP Diliman), or to a landing page (DepEd). DepEd Order 015 s. 2026 is retained development context, not a case source.
- Rules may have changed since retrieval.
